# YouTube Lecture Generator

A Python-based AI tool that transforms YouTube lecture transcripts into structured chapters, revision notes, key concepts, and summaries.

## Features

- Extracts transcripts from YouTube lectures
- Divides lectures into time-based chapters
- Generates AI-powered revision notes
- Extracts key concepts
- Creates concise lecture summaries
- Cleans common transcript and speech-to-text errors
- Provides an interactive Gradio interface

## Technologies Used

- Python
- Gradio
- Hugging Face Transformers
- FLAN-T5
- KeyBERT
- Sentence Transformers
- YouTube Transcript API
- Scikit-learn
